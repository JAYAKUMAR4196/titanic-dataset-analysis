# Titanic Dataset Analysis

**Data Analysis Project — Week 4, Data Science with Python**

## Project Overview

This project analyzes the Titanic passenger dataset to identify patterns in survival outcomes, with a focus on **sex, passenger class, and age**.

## Files

- `Titanic_Dataset_Analysis.ipynb` — Complete Jupyter Notebook containing the analysis and visualizations.
- `Titanic_Dataset_Analysis_Report.docx` — Project report.
- `Titanic-Dataset.csv` — Dataset used by the notebook, if included in the original project files.

## Key Findings

- Overall survival rate: **38.4%**
- Female survival rate: **74.2%**
- Male survival rate: **18.9%**
- 1st class survival rate: **63.0%**
- 2nd class survival rate: **47.3%**
- 3rd class survival rate: **24.2%**
- Child (0–12) survival rate: **58.0%**
- Senior (60+) survival rate: **22.7%**
- 1st class women survival rate: **96.8%**
- 3rd class men survival rate: **13.5%**

## Data Cleaning

The report documents the following preprocessing:

- Missing `Age` values were filled using the median age.
- Missing `Embarked` values were filled using the most common port.
- `Cabin`, `Ticket`, `Name`, and `PassengerId` were dropped for this analysis.

## Tools

- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

## How to Run

1. Clone or download this repository.
2. Make sure the dataset file used by the notebook is present in the same folder.
3. Open `Titanic_Dataset_Analysis.ipynb` in Jupyter Notebook, JupyterLab, VS Code, or Google Colab.
4. Run the notebook cells from top to bottom.
